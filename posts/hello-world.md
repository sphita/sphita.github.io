# Welcome to the Sphita Blog

This is our new markdown-powered blog system. It is designed to be **completely hassle-free**.

### How to write a new blog:
1. Create a `.md` file inside the `posts/` folder.
2. Write your content using standard Markdown.
3. Add a new entry to `blog-index.js`.

That's it! The system automatically fetches your markdown file, converts it into beautiful HTML, and displays it with our custom glassmorphic styling.

## Why this is great for developers
- **No databases**: Everything lives in your GitHub repository.
- **No compiling**: No Jekyll or static-site generators to debug. 
- **Code Highlights**: You can write code blocks natively:

```python
import datasets
print("Hello, Open Source!")
```
