# Sphita Website Specifications

## Overview
This document outlines the architecture and design of the Sphita web presence.

- **Hosting**: GitHub Pages
- **Repository Name**: `sphita.github.io` (Standard GitHub Org Pages naming convention)
- **Tech Stack**: Static HTML5, modern CSS3 (Flexbox/Grid, CSS Variables), Vanilla JavaScript.
- **SEO Strategy**: 
  - Semantic HTML tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
  - Comprehensive `<meta>` tags (description, keywords, viewport).
  - Open Graph tags for social sharing (Discord, Twitter, LinkedIn).
- **Core Pages**:
  - `index.html`: The landing page highlighting the mission, datasets focus, and ecosystem.
  - `about.html`: Details about the organization, the open-first philosophy, and leadership.

## Sub-Repositories
- **Documentary Sync**: All development logs and timestamped updates from the `.mds/` directory will be synced to the `documentary-mds` repository. This provides full transparency to the open-source community regarding our daily operations.
